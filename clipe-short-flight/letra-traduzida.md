## Pontos para decidir

- **"Another cowboy shot"**: traduzi como "plano americano", o enquadramento de cinema do joelho para cima, porque a música inteira é narrada como se fosse um filme. Se a ideia era "mais uma dose", troco para "Mais uma dose."
- Entre 2:31 e 3:35 a música é só instrumental. Esse trecho pede imagem sem letra, ou uma frase-título solta ("Voo curto, queda livre.").
